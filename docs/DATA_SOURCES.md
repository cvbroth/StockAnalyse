# 数据源选择与复权方式

| 项目 | 腾讯 `--tx` | Tushare `--tushare` |
|---|---|---|
| 个股覆盖 | 沪深 | 沪深京 |
| Token | 不需要 | 需要 |
| 保存方式 | 腾讯成品前复权价格 | 未复权价格和每日复权因子 |
| 更新单位 | 每只股票 | 每个交易日 |
| 初始化速度 | 可并发，通常更适合普通用户 | 取决于账号接口频率 |
| 复权变化 | 除权后需重取历史窗口 | 筛选时按最新因子动态计算 |

腾讯模式适合没有Tushare正式权限、只需要沪深市场、希望免费运行的用户。

Tushare模式适合同时满足以下条件的用户：

- 需要北交所数据；
- Token具有 `daily` 和 `adj_factor` 权限；
- `adj_factor` 调用频率足以完成初始化。

如果服务端提示复权因子每小时只能请求一次，初始化250个交易日将耗时很长，
应优先选择腾讯。

## 为什么不能在同一个数据库中切换

不同平台的复权算法、价格精度和更新时间可能不同。如果前半段历史来自一家、
后半段来自另一家，切换位置可能产生并不存在的价格跳空，继而影响均线、收益率、
突破和相对强度。

因此每个数据库只能绑定一个个股数据源。需要换源时创建新的数据库：

```bash
python -m app.cli.update --init --tx --days 250 --db data/market_tx.db
```

## 前复权计算

Tushare模式保存原始价格和复权因子，筛选时计算：

```text
前复权价格 = 原始价格 × 当日复权因子 ÷ 当前窗口最新复权因子
```

腾讯模式保存的已经是前复权价格，因此数据库中的 `adj_factor` 固定为1，分析层
不会再次复权。成交量在两种模式下都保持原始“手”数。
