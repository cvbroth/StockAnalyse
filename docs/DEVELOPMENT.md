# 开发与测试

自动化测试不访问腾讯或Tushare网络接口，使用内存数据和临时SQLite数据库。

运行全部测试：

```bash
python -m unittest discover -s tests -v
```

运行语法检查：

```bash
python -m compileall -q app tests
```

测试重点包括：

- 项目配置优先级和跨平台相对路径；
- 数据源绑定及禁止混合；
- 腾讯和Tushare字段标准化；
- 前复权计算；
- 五项技术规则和基础过滤；
- 全市场百分位与小样本模式；
- SQLite质量检查；
- 从数据库到输出文件的完整筛选链路；
- 新旧命令入口的兼容性。

提交代码前应确保以上两条命令成功。网络接口变动需要单独人工验证，避免CI消耗
额度或因外部服务波动产生误报。
